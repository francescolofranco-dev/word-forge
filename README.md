# WordForge

WordForge is an Android vocabulary trainer built with Kotlin, Jetpack Compose, Room, and spaced repetition.

## Statistics

Tap the chart icon on the home screen to see items added over the last seven local calendar days, the current distribution across learning tiers, and correct/incorrect review totals. Statistics include saved words and verb conjugations; deleted items are excluded.

## Build and test

```sh
./gradlew testDebugUnitTest
./gradlew lintDebug
./gradlew assembleDebug
```
